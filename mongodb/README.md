สัปดาห์ที่ 1: สถาปัตยกรรมเว็บและโพรโทคอล HTTP
ข้อสอบปรนัย 10 ข้อ ข้อละ 1 คะแนน รวม 10 คะแนน
ข้อ 1) HTTP response body มักใช้เก็บสิ่งใด?
*
1/1 ข.
ก. IP address ของ Client เท่านั้น
ข. เนื้อหาทรัพยากร เช่น HTML หรือ JSON
ค. ชื่อ method ของ request เท่านั้น
ง. หมายเลข port ของ Server เท่านั้น
ข้อ 2) HTTP method ใดใช้ขออ่านทรัพยากรโดยทั่วไป?
*
1/1 ง.
ก. PATCH
ข. DELETE
ค. POST
ง. GET
ข้อ 3) เมื่อ Browser ขอหน้าเว็บ ขั้นตอนใดเกิดขึ้นก่อนการ Render HTML โดยทั่วไป?
*
1/1 ค.
ก. ส่งอีเมลยืนยัน
ข. สร้างฐานข้อมูลใหม่
ค. ส่ง HTTP request และรับ HTTP response
ง. บันทึกข้อมูลลง LocalStorage เสมอ
ข้อ 4) HTTPS เพิ่มคุณสมบัติสำคัญใดให้ HTTP?
*
1/1 ค.
ก. ทำให้ HTTP เป็น stateful โดยอัตโนมัติ
ข. ทำให้ URL ไม่ต้องมี domain
ค. การเข้ารหัสและตรวจสอบความถูกต้องผ่าน TLS
ง. แทนที่ HTML ด้วย JSON
ข้อ 5) HTTP status code กลุ่ม 2xx หมายถึงอะไร?
*
1/1 ก.
ก. คำขอสำเร็จ
ข. เกิดข้อผิดพลาดฝั่ง Client
ค. ต้องเปลี่ยนเส้นทางเสมอ
ง.เกิดข้อผิดพลาดฝั่ง Server
ข้อ 6) ส่วนใดของ URL ระบุโพรโทคอลที่ใช้สื่อสาร?
*
ค.
ก. Fragment เช่น #details
ข. Query string เช่น ?page=2
ค. Scheme เช่น https
ง. Path เช่น /products
ข้อ 7) HTTP มีลักษณะ stateless หมายความว่าอย่างไร?
*
1/1 ก.
ก. แต่ละ request เป็นอิสระ และเซิร์ฟเวอร์ไม่จำสถานะเดิมโดยอัตโนมัติ
ข. Client ติดต่อ Server ได้เพียงครั้งเดียว
ค. HTTP ไม่สามารถส่งข้อมูลแบบข้อความได้
ง. เซิร์ฟเวอร์เก็บ session ของผู้ใช้เสมอ
ข้อ 8) องค์ประกอบหลักของสถาปัตยกรรมเว็บแบบ Client–Server คือข้อใด?
*
1/1 ค.
ก. Server ส่ง request ให้ Client เท่านั้น
ข. Client และ Server ต้องอยู่เครื่องเดียวกัน
ค. Client ส่ง request และ Server ส่ง response
ง. Browser ทำหน้าที่เป็นฐานข้อมูล
ข้อ 9) ส่วนใดของ HTTP message ใช้ส่ง metadata เช่น Content-Type?
*
1/1 ก.
ก. Header
ข. Status line เท่านั้น
ค. URL fragment
ง. Payload เท่านั้น
ข้อ 10) ข้อใดเป็นความหมายที่ถูกต้องของ HTTP 404?
*
1/1 ง.
ก. ผู้ใช้ไม่ได้รับอนุญาตเสมอ
ข. คำขอสำเร็จ
ค. เซิร์ฟเวอร์ล่มทุกกรณี
ง. ไม่พบทรัพยากรที่ร้องขอ
